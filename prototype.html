🛠️ Student Innovation

Meet the Prototype

Ocean × Eco-Tech is a student-developed marine waste collection concept designed to explore how practical hardware and digital monitoring can work together to support cleaner aquatic environments.

🌊 The System

How Ocean × Eco-Tech Works

The prototype combines a floating collection mechanism with sensing, sorting and digital reporting concepts. The system is being developed progressively, with hardware-based functions becoming available as the relevant components are integrated and tested.

🚤

Marine Waste Collector

The proposed platform is designed to move across the water surface and collect floating waste. Collected material can then be directed toward separate compartments according to the intended sorting workflow.

Prototype hardware integration in progress
📡

Digital Monitoring

The accompanying web application provides the interface for future sensor information, verified locations, waste records, reporting and project analytics.

✨ Design Goals

Built for Responsible Monitoring

The system is designed around transparency: the application should clearly distinguish between proposed functionality and verified hardware data.

📡 Real Sensor Data

Sensor dashboards will display measurements only after compatible prototype hardware is connected and verified.

📍 Verified Locations

GPS monitoring points will only be displayed when a real hardware location is available.

♻️ Waste Documentation

Users can document waste through the reporting system while collection history can be built from actual records.

🛡️ Transparent Analytics

Project analytics will distinguish recorded activity from sensor-dependent environmental measurements.
