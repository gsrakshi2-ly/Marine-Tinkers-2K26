🧪 Prototype Testing

Testing helps identify problems before real-world deployment.

📡

Check whether the sensor responds consistently to the intended test conditions.

⚙️

⚠️ Prototype Note

The website represents the project concept and prototype architecture. Actual component behavior, detection range, motor performance and collection efficiency should be determined through physical testing rather than assumed from the website.

🌊 From Prototype to Possibility

A working prototype is the first step. With further testing, better sensing, improved mechanics and responsible design, the concept could continue evolving.
