⚙️ TECHNOLOGY

Technology Behind the Project

The project combines physical engineering, electronics and web technology to create a foundation for marine-waste monitoring.

💻 DIGITAL SYSTEM

Connecting hardware and software

The web platform is designed to receive information from the prototype and present it clearly. Until hardware communication is established, the interface intentionally remains in an awaiting state.

🧠

Microcontroller

The control system can process information from connected sensors and coordinate the prototype's hardware functions.

📡

Sensors

Sensors are intended to provide genuine measurements that can later be transmitted to the monitoring platform.

🌐

Web Platform

The web application provides a responsive interface for viewing data, exploring locations and documenting project activity.

📡 DATA INTEGRITY

No simulated measurements

The platform follows a real-data-first approach. Sensor readings, environmental scores, alerts, graphs and monitoring locations will only be shown when genuine data is available.

🔌

Awaiting Hardware

Hardware-dependent technology will become active after the prototype sensors and communication system are connected and tested.

🌱 OUR APPROACH

Technology is used as a tool for observation, documentation and responsible action—not as a replacement for verified environmental evidence.
